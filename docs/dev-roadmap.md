1. 挑下面**下一个未完成的最小切片**，做完勾选 `[x]` 并追加周期日志
2. 增量修改：已有文件禁全量重写，用精确替换
3. 不测试不勾选；失败如实记录，禁谎报

5. 路由陷阱：新 router 必须在 `src/main.py` include_router + 验证非404
